# 금융 실무 자동화 포트폴리오

금융 문서와 엑셀을 반복해서 손으로 옮기고 맞추는 작업을 스크립트로 자동화합니다.
결과를 그대로 믿으라고 하지 않고, **검증 시트를 같이 드립니다.** 합계가 맞는지, 겹치는 기간의 숫자가 같은지, 자동으로 읽지 못한 줄이 어디인지 표시합니다.

| | 데모 A: 사업보고서 PDF → 재무 요약 엑셀 | 데모 B: 잔고 시트 → 거래원장·수익률 |
|---|---|---|
| 입력 | DART 사업보고서 PDF (여러 해) | 기준일별 수익자 잔고 시트만 있는 엑셀 |
| 출력 | 연도별 요약재무, 주요비율, 검증 시트 | 거래내역(설정/추가설정/환매 추정), 수익자별 손익·XIRR, 펀드 현금흐름, 검증 시트 |
| 예시 | 삼성전자 2021·2023 보고서 → 2019~2023 5개년 | 가상 펀드 12개월 × 12명 → 거래 31건 |
| 검증 | 원문 숫자 대조, 자산 = 부채 + 자본, 겹치는 연도 일치 | 정답 거래와 31/31 일치, 엑셀 XIRR 예제와 일치, 평가금액 오류 감지 |

## 데모 A — 사업보고서 PDF → 재무 요약 엑셀

```bash
cd demo_a_financials
python fetch_dart_pdf.py 20240312000736 -o samples/samsung_2023.pdf   # DART 접수번호로 PDF 받기
python extract_summary.py samples/samsung_2023.pdf samples/samsung_2021.pdf -o output/삼성전자_요약재무_2019-2023.xlsx
python test_extract.py
```

- 회사마다 다른 양식을 처리합니다: 단위(원/천원/백만원/억원 → 백만원), `△`·괄호 음수, `ㆍ` 들여쓰기 유무, 항목명 차이(매출액/영업수익 등)
- 삼성전자, 카카오, 에코프로비엠 2023 보고서로 확인했습니다. 세 회사 모두 자산 = 부채 + 자본 검증에서 차이 0
- 에코프로비엠 보고서처럼 PDF에서 칸이 빠져 어느 연도 값인지 애매한 줄은 추측하지 않고 '확인 필요'로 남깁니다
- 한계: 요약재무정보 표만 읽습니다(현금흐름표 미포함). 결산월이 12월이 아닌 회사, 스캔본 PDF는 별도 작업이 필요합니다

## 데모 B — 잔고 시트 → 거래원장·수익률

```bash
cd demo_b_fund_ledger
python make_sample.py                      # 가상 데이터 생성 (실제 고객 데이터 아님)
python build_ledger.py samples/잔고_가상펀드.xlsx -o output/거래원장_가상펀드.xlsx
python test_ledger.py
```

- 시트 이름이나 '기준일' 셀에서 날짜를 읽고, `수익자번호`/`계좌번호`, `보유좌수`/`좌수` 같은 다른 헤더 이름도 찾습니다
- 잔고 변화로 거래를 추정합니다: 0에서 증가 → 설정, 증가 → 추가설정, 감소 → 일부환매, 0이 됨 → 전액환매
- 한계: 두 기준일 사이에 여러 번 거래했으면 순변동 1건으로만 보입니다. 거래는 해당 기준일 기준가로 계산합니다

## 필요 환경

Python 3.10+, `pip install pdfplumber openpyxl`
